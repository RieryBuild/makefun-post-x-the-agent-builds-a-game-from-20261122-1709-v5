MOON MOTH — a tiny catch-style game built from one prompt: a glowing neon moth with big luminous wings flutters through a moonlit night garden, catching drifting moon-petals and dodging shadow bats. The video shows the agent building it from that one prompt, then the game running. Play it in game/index.html — move with arrow keys, mouse or touch; catch petals, dodge bats, 3 lives.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
